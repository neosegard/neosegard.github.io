Démarche Éco-responsable

Comment ce site a été pensé pour consommer le moins possible

Optimisations mises en place

Aucune image

Le site n'utilise aucune image : tous les effets visuels (couleurs, ombres, animations) sont faits en CSS. Les images sont souvent la ressource la plus lourde d'une page web.

Mise en cache

Bootstrap et les polices sont chargés depuis des CDN : s'ils sont déjà en cache dans le navigateur du visiteur, ils ne sont pas retéléchargés. Les fichiers CSS et JS du site sont mis en cache par le serveur.

Polices optimisées

Seulement deux polices (Crimson Pro et Inter), avec uniquement les graisses utilisées, preconnect vers Google Fonts et display=swap pour afficher le texte sans attendre.

Code léger

HTML sémantique, CSS organisé avec des variables (un seul fichier pour les deux thèmes), JavaScript minimal sans bibliothèque supplémentaire. HTML, CSS et JS sont séparés.

Thème sombre

Le thème sombre réduit la consommation d'énergie sur les écrans OLED. Le choix du visiteur est mémorisé pour ses prochaines visites.

Cookies & RGPD

Les cookies sont gérés par Cookiebot : Google Analytics n'est chargé qu'après le consentement du visiteur, ce qui évite des requêtes inutiles.

Empreinte carbone

Le badge ci-dessous indique l'empreinte carbone estimée d'une visite sur ce site, calculée par Website Carbon.
